# 聖奧爾德里克港（Saint Aldric Harbour）研究原型報告

> 狀態：**獨立研究原型，不是遊戲入口。** 與主專案共用 `three` 版本（0.187.0），但自成一包、不進 Pages、不被 `npm run validate`／build 掃描。任務 Issue：#144。

## 1. 目的與範圍
使用者要求以「網頁碰瓷虛幻五引擎」為目標，做一份**全程式生成、單檔、無任何外部圖片／模型／音檔／字型／網路**的擬真中世紀港鎮。標竿地點為波羅的海岸的維斯馬（Wismar，北緯 53.9°、13–15 世紀漢薩城市）。保留既有玩法：行走、釣魚、划船、晝夜、天氣；新增農耕（中世紀作物）、背包、更深的釣魚、存檔、四季、畫質選單（低／中／高／極高）。目標裝置 POCO F8 Ultra，內部渲染短邊 720–1080（低）與 1080–1440（其餘）。

## 2. 檔案
| 路徑 | 內容 |
|---|---|
| `saint-aldric-harbour.html` | 建置好的單檔（約 850 KB，v8） |

偵錯入口只有網址加 `?debug=1` 才會掛 `window.__game` 等；其他網址參數：`q`（畫質）、`rs`、`hour`、`doy`、`wx`、`still`、`autostart`、`fresh`。

## 3. 技術概要
- **渲染**：three.js r187、WebGL2；大氣 LUT 天空（Hillaire 式）、PMREM 環境光、自動曝光、AgX、Jimenez 泛光、半浮點 HDR + MSAA、動態解析度。材質用 `patch()` 補丁加上 CSM 串接。
- **材質**：全程式 PBR，紋理陣列在 GPU 上烘焙（磚、石、瓦、茅草、樹皮含樺樹／山毛櫸等）。
- **海水**：CPU IFFT 譜域波（`ocean.js`）＋Jacobian 泡沫、Beer–Lambert 吸收、港內阻尼與毛細波紋／藻色；舊 Gerstner 路徑保留為 `?gerstner=1`。
- **植被**：
  - 闊葉樹為分枝層級（樹幹→主枝→枝→細枝，四層彎曲錐管）＋只長在枝梢的葉簇；葉法線向樹冠外側彎，冠內 AO；遠景用橢球葉卡 LOD。
  - 1024 葉片貼圖（真實單片葉，中肋、側脈、深邊）；針葉為主軸加對生小枝。
  - 草為頂點著色器放置、貝茲曲線葉片＋穗狀種穗＋五種花形；樹冠散射補光。
- **世界**：維斯馬式平面圖（廣場、城牆環、護城河、港灣與防波堤、碼頭）、城門可通行（5/5 以 BFS 驗證）。
- **玩法**：農耕、背包、釣魚、可划船、存檔（localStorage `aldric.save`＋備份、匯出／匯入 JSON）、一年 32 天四季（現實 24 分鐘＝1 天）。
- **UI**：浮動搖桿、按鈕 ≥44 px、選單分頁（畫質／存檔／說明）、首次情境提示。

## 4. 研究依據
- Kuth 等人 2025〈Real-Time GPU Tree Generation〉（HPG）：分枝層級＋葉簇。
- Kusternig 2008、Habel 2010：葉片法線／透光圖／厚度。
- GPUOpen 程序化草地、Ghost of Tsushima 草（GDC）：貝茲曲線草葉、風移動控制點。
- NeuralSpecOcean（MIT）、Grassworks 展示：海洋與草木對標等級。

## 6. 尚未做到（20 張審查截圖的盤點）
**模型與幾何**
1. 出生點雜亂：站在碼頭根部，眼高有石壓頂樑、一個純黑方塊、一個過大木箱貼鏡頭。
2. 黑色漂浮板（城堡視角天空、巷弄上空長條黑樑）——不亮的面，成因未查明。
3. 茅草屋頂上方有懸空窗框（窗後無牆）。
4. 城門街半木構房屋的大窗洞全黑、無玻璃與室內；有一扇門板立在牆外。
5. 圓塔頂垛口像分開的深色薄板。
6. 岸邊下水石階呈鋸齒斜塊；碼頭外側橫木偏黑。
7. 城堡庭院裂石貼圖尺度過大。

**光照與曝光**
1. 背光牆面（如圓塔底部）近乎純黑，白天天空補光對立面不夠。
2. 夜景廣場鋪面過亮發白；星星太密太大。
3. 多張截圖天空深藍、地面發白：判斷是 SwiftShader 低幀率下自動曝光未收斂，**未證實**，需真機確認；尚未加「瞬間收斂」測試參數。
4. 鑽到碼頭下方時水面消失、海床純白。

**季節與天氣**：冬天只有地面邊緣有雪，屋頂與鋪面無雪；秋天只檢查第 1 天；雨天無積水與漣漪。

**植被與生態**：近看仍偏畫風；楊樹像帶白斑的柱狀常春藤；灌木多為圓球（新分枝結構未做）；花遠看幾乎不可見；風擺與透光未做動態驗證；AO 開關、平面反射未實作。

**小鎮與玩法**：農地鏡頭取不到農地位置（`__farm.site` 缺失），**農地畫面未驗證**；市集空曠、街道兩側長磚塊重複、缺小物件與路人；「面向市集的建築」「木板拱門」未做。

**完全沒驗證**：真機 FPS／發熱、聲音、真機觸控、Safari／Firefox、柯克船上下船與划槳。
