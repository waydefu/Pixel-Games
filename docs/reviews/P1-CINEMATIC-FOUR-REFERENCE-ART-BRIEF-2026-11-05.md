## 3. G3：先做英雄視角，不是先灑滿全圖

**樣板位置與機位**：先在現有可到達的漁港／街區驗證「一個主地標＋周邊生活建築＋碼頭＋峽灣山體」。最先攻克圖 D 所指的白日空間品質，避免直接造一座不合世界觀、無碰撞與導航的超高摩天建築。

1. **遠景剪影與高度層級**：主地標（鐘樓／瞭望塔／舊燈塔）形體獨立於背景山脊，周邊 6 棟原有漁屋逐棟有差異，不被遠山吞掉；先建可站的連續台地與道路，再放 tower，避免懸空與船礁壓疊。
2. **前中後景三層**：前景植物／柵欄與靠岸礁石、中景凹窗漁屋／石路／木橋、遠景峽灣岩壁／天空；使用遮擋與局部明暗，而不是把物件平均撒進 3D 空間。
3. **岩壁與山型**：陡峭灰岩、坡面草與苔蘚分區、三層藍灰氣霧；海峽仍保持打開，山脈不堵視線。近景可先少量 procedural cliff silhouette，必要時局部法線／AO，**不整張山體套高成本 triplanar**。
4. **原創漁屋／地標**：在 PR #11 真凹窗基礎上細化窗框陰影、梁柱、瓦片／石基座／岸邊屋簷；G3 的船／水邊木板材質可做色彩／粗糙度改進，但不得引入任何重型海面技術。
5. **環境動態保留自然**：原有程序雲先維持低成本；雲影、炊煙、海鷗、風樹等留 G5，**除非 G3 的固定鏡頭顯示需要少量靜態構圖物件**，不要提前塞滿動態粒子。
6. **原創資產政策**：使用 `src/game/art.ts`／程序幾何或有合法來源的素材，禁止把這四張帶角色與浮水印的畫面切成背景、天空盒、紋理貼片。

## 4. G4：景深與泛光不是可有可無，但要作用在對的位置

- **Bloom（必做）**：亮點來源以窗燭、燈塔火焰、黃昏光源和少量粒子為主；調整 threshold + mip／半解析度，避免**整片白天雲層、海面、牆面都發光**。圖 A、B、C 的視覺力量來自明暗關係與局部亮度峰值，不是所有像素全亮。
- **DoF（必做）**：以 Quarter View 的人物／中景街區為焦平面，前景與遠景輕微失焦；第一人稱近牆應保持清晰（縮弱／停用），山海 vista 鏡頭亦需弱化，不能把圖 D 的山和建築糊成一片。
- **Film / Color Grading**：日間清透、日落暖金冷紫、夜間深藍配局部琥珀窗燈；先確定 G1 的 sky／fog／sea HDR linear→tone-map→sRGB 契約，避免 double tone mapping。高反差色群在畫面中仍要保留中間調與材質細節。
- **天空（非海洋）**：低成本多層 fBm 雲的尺度、密度、光側可隨時段變化；深夜星點只在天色足夠暗時可見。藍色星雲、魔法光柱屬風格特例，**先當 G4/G6 可選參考，不視為目前已實裝的日夜系統**。
- **避免昂貴水面**：海水維持 `ocean.ts` 現有 Fresnel／analytical sky tint／Gerstner-style waves；不導入 FFT、Planar Reflection、SSR、額外海水 pass，海面被全畫面 Bloom／DoF 處理的成本也需真機實測。

**驗收核心（逐項 PASS / FAIL / NOT RUN）**：

- **構圖**：固定機位下第一眼能指出主地標，前／中／遠景可分層且對應世界觀；不讓同一個重複材質填滿整個畫面。
- **色彩**：暖／冷相互襯托且曝光保留屋瓦、木梁、石壁細節；天空地平線與場景霧不斷裂。
- **細節**：靠近窗、牆、屋檐、石塊仍是真正幾何與材質，不是景深模糊遮瑕。
- **效果**：Bloom 有局部亮點，DoF 有明確焦點，basic 能回退且不黑屏；明暗不能犧牲 UI／角色可辨性。
- **效能**：相同 shot/viewport/DPR/quality 對比 p50/p95 frame、draw calls、GPU time（若可用）；POCO F8 Ultra 真機及熱降頻 **NOT RUN** 除非另有紀錄。60 FPS 是目標，不能把第三方遊戲的畫質與 FPS 數字冒充我們的實測。
