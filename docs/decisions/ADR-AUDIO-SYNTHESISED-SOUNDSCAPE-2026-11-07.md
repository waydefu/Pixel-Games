# ADR：音訊採用程序化合成的聲景（2026-11-07）

**狀態：採用。** 實作於 `src/game/audio-mix.js`（混音規則，純函式）與 `src/game/soundscape.ts`（Web Audio 引擎）。

## 背景
外部建議（未經核對的研究文字）主張「真實錄音 + 程序化變化 + 3D 空間音效」，並列出 OpenGameArt 的海浪與海鷗素材。

## 核對結果
- 兩個 OpenGameArt 素材頁（Beach Ocean Waves、Solo Seagull Sound Effects）在本專案環境回 HTTP 403，**無法讀取授權、作者、來源鏈或下載檔**。建議文字本身也承認海鷗素材取自另一段影片，授權鏈未確認。
- Sonniss 套件是專用授權（禁止獨立散布素材），本倉庫公開，不適合直接放入。
- 目前 repo 沒有任何音訊模組（已核對：無 `AudioContext`／`new Audio`）。

## 決定
海浪、風、樹葉、水拍擊、腳步、水花、釣魚聲屬於濾波雜訊與短脈衝，用 Web Audio 合成即可；海鷗、鐘聲、蟋蟀用小型合成器。優點：沒有授權問題、不增加下載量、音量與風場／浪潮／時間／位置完全同步。
缺點（照實記錄）：**海浪與海鷗的擬真度不如真實錄音**，且音量比例**只經離線渲染的頻譜與峰值檢查，沒有用耳朵與真機喇叭調過**。

## 之後換成錄音
引擎的每一層（`LAYERS`）都可以換成有明確授權、可核對來源的 CC0 錄音。換入前須在 `docs/ASSET-CREDITS.md` 記錄來源、作者、授權與取得方式；不可使用無法核對來源鏈的檔案。

## 混音規則（自訂，不是聲學標準）
見 `soundscapeMix`：海聲隨離岸距離衰減、村莊在山的背風處、西側山丘由樹木與風主導、夜晚由蟋蟀主導、船上只剩海面的低語與拍擊；總輸出經壓縮限幅器。
