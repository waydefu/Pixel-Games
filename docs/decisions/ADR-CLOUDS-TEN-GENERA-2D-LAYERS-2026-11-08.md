# ADR：天空雲改為十雲屬的 2D 分層，並以同一組雲層畫地面雲影

日期：2026-11-08　狀態：採用（真機與人眼驗收未完成）

## 背景
前一版高畫質用 28 步光線步進的體積雲板加 128 px 的 CPU 雲圖。Owner 在手機上指出：雲像大塊柔軟的霧，沒有立體感；後來又指出排列像方格、地上沒有雲影。對照畫面找到的原因：
1. 雲圖解析度與頻率太低，放大後是柔霧；
2. 雜訊場只切一道閾值，會蜿蜒成片，透視再把每一條拉成指向消失點的放射條紋（體積雲的「垂直窗簾」同源）；
3. 用細胞（Worley）格點與軸向對齊的雜訊，閾值切出來就是方格；
4. 地面雲影用另一張 CPU 雲圖，位置與天上看到的雲不同，而且薄雲疊起來處處都有遮蔽，只剩均勻變暗。

## 決定
- **十雲屬登記表**（`src/game/cloud-genera.js`）：WMO 十屬，4 種形態 × 3 個高度帶；天氣狀態（雲量、降水、對流、霧）→ 各屬占比；總雲量為各層獨立遮擋的聯集。曲線與尺度為本專案自行調校。
- **2D 分層**（`src/game/cloud-shader.ts`）：每屬一個平面，高度 H、格子大小 S（世界單位），雲是平面上的世界座標點。積雲＝一半雜訊場＋一半分開的雲塊；顆粒雲＝單倍頻窄閾值＋兩組轉角格線；受光＝密度往太陽方向偏移後的差；每個倍頻依像素足跡淡出。直射光用太陽色、陰影用天光；高層比低層更晚失去陽光。
- **雲影圖**（`src/game/cloud-shadow.ts`）：從太陽方向用同一組雲層畫一張小圖（256／128／64 px，每幀最多一次，軟體 GPU 不畫），地面與一般材質讀它；中心像素非同步讀回作為擋日光量。
- **日暈**：卷層雲出現時在 21.7° 畫一圈外緣漸淡、內緣偏紅的環。
- 移除 28 步體積雲與 3D 噪聲草稿。

## 為什麼不是真體積雲
參考的 MIT 專案（takustaqu/atmosphere）自己也只把積雨雲做成體積雲，積雲是 2D 雲塊；官方 three.js（0.187）沒有體積雲附加元件，官方 Sky 也是 2D 雲層。體積雲在手機上的成本與溫度未測，先用 2D 做到「分開的雲塊與受光立體感」，真體積雲留作之後的可選高畫質。

## 風險與限制
- 只在 SwiftShader 看過畫面；真機 GPU 時間、溫度**未測**。
- 積雨雲目前只有暗而厚的雲塊，砧狀雲塔、乳房雲、雲內閃電尚未做。
- 雲格子縮到約 70 世界單位（島約 100），所以走路時低層雲會有輕微視差；這是刻意取捨，讓雲影是走得進出的一塊一塊。
- 雲影強度（基本 .34／平衡 .48／高 .55）為目視調校，在陰暗天氣依天色變暗而減弱。
