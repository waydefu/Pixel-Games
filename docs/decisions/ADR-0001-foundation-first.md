# ADR-0001｜不預選遊戲類型及渲染引擎

狀態：提案（待 Owner 審查 PR）；日期：2026-11-04。

## 背景
原先有單檔地城 HTML 原型，但使用者要求新的像素遊戲，並指定先建立通用工程技能、工具及架構。因此既有原型不視為正式內容或硬性繼承。

## 決策提議
- P0 採用原生 ESM + DOM 靜態入口、少量純 JS 底層和 Node 內建測試，不依賴 bundler。
- 保留 GitHub Pages 的 main/(root) 選擇，不增加部署 token 或切 Actions。
- 首款遊戲決策前不加入玩法、地圖、戰鬥、武器、素材、第三方渲染引擎。
- 未來由遊戲需求決定 Canvas2D／PixiJS／Phaser／Three.js HD-2D；選型需有實機基準與替代方案。

## 代價
- 現階段是工程底座，不是直接可玩的作品。
- 原生 JS 目前沒有 TypeScript 靜態型別與 bundler 最佳化；若規模擴大再以新 ADR 升級。
- 共用平台目前只保證自身契約；真正遊戲玩法需求可能要求架構調整。

## 退場條件
選好遊戲後，如果新的引擎架構不再需要這些 core abstraction，可移除，避免過度設計。
