# 品質與驗收門檻

狀態分開標記：**已自動檢查**／**需人工**／**未建立**。這些是工程驗收條件，不是目前已通過的真機測試。

## P0 工程基線
- 自動：`npm run check`：必要文件、主頁參照、JavaScript 語法、遊戲入口登錄檢查。
- 自動：`npm test`：時間步、場景切換、像素座標、登錄路徑的單元回歸。
- 待驗：GitHub Actions 上述兩項狀態；首次 PR 結束前不得宣稱 CI 綠燈。
- 待人工：桌面及手機瀏覽器開啟根目錄入口，確認標題、中文字、橫／直向、不因 JS 失敗變空白。

## 第一款遊戲才啟動
- **功能**：玩法操作、暫停／重開、場景切換、存檔（如有）、碰撞地圖可通行性、觸控多點、鍵鼠。
- **畫面**：像素邊緣清晰；畫面比例、相機、UI safe area；沒有不可見牆、箱子卡角、強制旋轉裁切。
- **效能**：以 60 FPS（16.67 ms/frame）作高階目標，30 FPS 作可接受 fallback 候選；**目標不等於保證**。需報 p50/p95 frame time、長時間熱降頻、場景與渲染設定。
- **可及性**：可聚焦操作、可讀文字、觸控目標大小、減少動態效果選項、失效時的提示。
- **測試設備**：Chrome 桌面、Android Chrome 橫豎屏、iOS Safari（若能取得設備）；保留使用者實際設備資料而不是推估成績。
- **瀏覽器**：Playwright smoke/E2E 是候選，需等遊戲特性確定才寫合理的操作斷言。
