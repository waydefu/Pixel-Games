# 原創遊戲概念與範圍

1. 讀 AGENTS.md、docs/GAME-PROPOSAL-TEMPLATE.md 與當前 Issue。
2. 區分使用者已指定、合理建議及尚未決定；不要把先前地城試作當成前提。
3. 分析玩家的 30–60 秒自然互動、裝置、操作與反饋；**休閒無目標遊戲不需要強加勝負、主線任務或打卡機制**，先設計最小可漫遊片段。
4. 可以提供 2–3 個有差異的方向供 Owner 選擇，但在批准前不建立遊戲模組或素材。
5. 完整記錄決策、非目標、接受條件與引用的素材／技術來源；需要時才更新 ADR。
